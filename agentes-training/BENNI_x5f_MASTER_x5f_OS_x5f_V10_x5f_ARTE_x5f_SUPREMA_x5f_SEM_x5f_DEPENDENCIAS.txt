TEMPLATE 1: HALO v2 - RESPIRAÇÃO VIA SCROLL + IDLE, NÃO MIC
Nome: HALO - O SITE QUE RESPIRA COM VOCÊ, SEM PRECISAR DE MIC

Conceito: Site tem ritmo próprio. Quando você scrolla rápido, ele ofega. Quando para, ele respira fundo. Luz central pulsa com idle time, não com sopro.

Tech stack sem mic:
- Lenis para scroll velocity
- Theatre.js para breath timeline
- Lygia circleSDF + cnoise para halo orgânico
- R3F ShaderMaterial com uScrollVelocity + uIdleTime + uTime

Código:
import Lenis from 'lenis'
import { shaderMaterial } from '@react-three/drei'

const HaloMaterial = shaderMaterial(
  { uTime: 0, uScrollVelocity: 0, uIdleTime: 0, uPointer: [0,0] },
  // vertex
  `varying vec2 vUv; void main(){ vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position,1.0); }`,
  // fragment com Lygia
  `
  #include "lygia/sdf/circleSDF.glsl"
  #include "lygia/generative/cnoise.glsl"
  #include "lygia/color/palette.glsl"
  varying vec2 vUv;
  uniform float uTime;
  uniform float uScrollVelocity;
  uniform float uIdleTime;
  uniform vec2 uPointer;

  void main(){
    vec2 st = vUv * 2.0 - 1.0;
    st += uPointer * 0.1; // segue pointer sutil

    float breath = sin(uTime * 0.5 + uIdleTime) * 0.1 + 1.0;
    breath += uScrollVelocity * 0.2; // scroll rápido aumenta

    float d = circleSDF(st * breath);
    float n = cnoise(st * 2.0 + uTime * 0.1) * 0.1;
    d += n;

    vec3 color = palette(d + uTime * 0.05, vec3(0.5,0.5,0.5), vec3(0.5,0.5,0.5), vec3(1.0,1.0,1.0), vec3(0.0,0.33,0.67));
    float alpha = 1.0 - smoothstep(0.0, 1.0, d);
    gl_FragColor = vec4(color, alpha * 0.6);
  }
  `
)

const lenis = new Lenis()
let idleTime = 0
let lastScroll = 0

lenis.on('scroll', ({ velocity })=>{
  lenis.raf
  lastScroll = performance.now()
  material.uniforms.uScrollVelocity.value = Math.abs(velocity) * 0.01
})

function raf(time){
  lenis.raf(time)
  const now = performance.now()
  idleTime = (now - lastScroll) / 1000 // segundos parado
  material.uniforms.uIdleTime.value = idleTime
  material.uniforms.uTime.value = time * 0.001
  requestAnimationFrame(raf)
}
raf()

TEMPLATE 3: LUMEN v2 - LUZ QUE SEGUE POINTER + FOCUS, NÃO VOZ
Nome: LUMEN - O SITE QUE SÓ ILUMINA ONDE VOCÊ OLHA

Conceito: Site todo escuro (obsidian). Só ilumina onde pointer passa ou onde keyboard focus está. Texto só aparece na luz. Se você move rápido, luz grande mas difusa. Se move devagar, luz pequena e nítida. Sussurro virou lentidão, grito virou velocidade.

Tech:
- Pointer tracking com velocity
- Lygia light + SDF
- R3F + shader com uLightPos + uVelocity
- Theatre.js para luz que respira

Código sem voz, com pointer:
const pointer = { x: 0.5, y: 0.5, velocity: 0 }
let lastX = 0, lastY = 0, lastTime = 0

window.addEventListener('pointermove', (e)=>{
  const now = performance.now()
  const dx = e.clientX - lastX
  const dy = e.clientY - lastY
  const dt = now - lastTime
  const velocity = Math.sqrt(dx*dx + dy*dy) / dt

  pointer.x = e.clientX / innerWidth
  pointer.y = 1.0 - e.clientY / innerHeight
  pointer.velocity = Math.min(1, velocity * 0.1)

  material.uniforms.uLightPos.value = [pointer.x, pointer.y]
  material.uniforms.uVelocity.value = pointer.velocity

  lastX = e.clientX
  lastY = e.clientY
  lastTime = now
})

// Keyboard: Tab move luz para elemento focado
document.addEventListener('focusin', (e)=>{
  const rect = e.target.getBoundingClientRect()
  gsap.to(material.uniforms.uLightPos.value, {
    x: (rect.left + rect.width/2) / innerWidth,
    y: 1.0 - (rect.top + rect.height/2) / innerHeight,
    duration: 0.8,
    ease: 'power2.out'
  })
})

Shader:
uniform vec2 uLightPos;
uniform float uVelocity;
uniform float uTime;
varying vec2 vUv;

void main(){
  float d = distance(vUv, uLightPos);
  float size = 0.2 + uVelocity * 0.3; // rápido = luz grande difusa, lento = pequena nítida
  float light = 1.0 - smoothstep(0.0, size, d);
  light *= 1.0 - uVelocity * 0.5; // rápido menos intenso
  light += sin(uTime + d * 10.0) * 0.02; // respiração

  vec3 color = vec3(light);
  gl_FragColor = vec4(color, light);
}

Narrativa: Sobre atenção. O que você ilumina existe. O resto é escuro. Usuário percebe que atenção é escolha. Texto: "Você não vê o que está lá. Você vê onde ilumina."

A11y: Sem pointer, luz segue focus. Tab navega e ilumina. Sem JS, texto todo visível com fundo escuro e sem efeito de luz (progressive enhancement).
