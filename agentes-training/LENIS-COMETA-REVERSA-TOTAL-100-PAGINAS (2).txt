CAPITULO 1: O QUE E LENIS E POR QUE MATOU O LOCOMOTIVE
================================================================================
Lenis = smooth em latim. Criado pela Darkroom Engineering (ex-Studio Freight).
Nao e scroll hijack burro. Ele NAO cria div com transform translate.

Principio 1: Roda em cima do scroll NATIVO. Deixa browser com overflow auto nativo. So atrasa targetScroll ate animatedScroll usando lerp/duration. Por isso sticky, anchor, find-in-page, acessibilidade continuam.

Principio 2: Single RAF. Um unico requestAnimationFrame. Se usa GSAP, injeta lenis.raf(time) no ticker do GSAP. Um frame budget.

Principio 3: Virtual Scroll Layer. Wheel, touch, keyboard normalizados em virtual-scroll.ts para deltaY/X consistente. Nunca le direto do wheel sem passar por prevent/virtualScroll/allowNestedScroll.

Manifesto: Locomotive morreu porque era pesado, bugava sticky e tinha transform. Lenis nasceu para ser 3kb, sem dependencias, e fazer 1 coisa muito bem.

Instalacao:

Metodos internos:
init(): adiciona classes lenis, lenis-smooth, liga virtualScroll.on('scroll'), dimensions.on('resize'), anchors click delegation, autoRaf loop

onVirtualScroll({deltaX, deltaY, event}):
  se isStopped return
  se prevent(node) return
  se virtualScroll(e) === false return
  se allowNestedScroll: percorre composedPath e verifica se algum elemento tem overflow scroll e esta no meio, se sim deixa nativo
  gestureOrientation filter
  overscroll check
  delta = orientation vertical ? deltaY : deltaX
  targetScroll += delta * multiplier
  clamp 0..limit se !infinite

raf(time):
  dimensions.resize() se dirty
  lastScroll = animatedScroll
  se animate.isRunning: animate.advance(time); animatedScroll = animate.value
  senao lerp mode: animatedScroll = lerp(animatedScroll, targetScroll, lerp)
  infinite wrap: se <0 => limit+animated, se >limit => animated-limit
  clamp se !infinite
  velocity = animated - last
  direction = sign(velocity)
  escreve DOM: window.scrollTo(0, animated) ou wrapper.scrollTop
  emit scroll event
  se target proximo de animated (<0.01) -> isScrolling false

scrollTo(target, options):
  target: number | string selector | HTMLElement | 'top'|'bottom'|'left'|'right'|'start'|'end'
  resolve:
    number => direto
    'top'/'start' => 0
    'bottom'/'end' => limit
    string #id => getElementById(decodeURIComponent(id)) || querySelector (fix #520 para ids com chars especiais como †)
    string selector => querySelector
    HTMLElement => offsetTop relativo + offset + scroll-margin CSS (fix #507 respeita scroll-margin)
  options: offset, lerp, duration, easing, immediate, lock, force, onComplete, userData
  cria animate.fromTo

stop()/start(): isStopped flag, class lenis-stopped
resize(): dimensions.resize()
destroy(): remove classes, cancel raf, remove listeners

Animate:

  fromTo(from,to,{lerp,duration,easing,onComplete}): seta from/to, currentTime=performance.now(), isRunning true

Neste capitulo aprofundamos o nivel 1 da engenharia reversa.

Topico 1: Como o Lenis calcula velocity e direction para efeitos skew e parallax.

Codigo de exemplo 1:

```js
// Exemplo 1 - Velocity based distortion
import Lenis from 'lenis'
import 'lenis/dist/lenis.css'
import gsap from 'gsap'

const lenis = new Lenis({
  autoRaf: true,
  lerp: 0.060000000000000005,
  wheelMultiplier: 0.8500000000000001,
  gestureOrientation: 'both',
  smoothTouch: false,
  infinite: false,
  orientation: 'vertical'
})

lenis.on('scroll', ({scroll, velocity, direction, progress, limit}) => {
  // Efeito 1: skew, scale, opacity baseado em velocity
  const skew = velocity * 0.12000000000000001
  const scale = 1 + Math.abs(velocity) * 0.001
  document.querySelectorAll('.item-1').forEach(el => {
    el.style.transform = `skewX(${skew}deg) scale(${scale}) translate3d(0, ${scroll*0.1}px, 0)`
    el.style.opacity = `${1 - progress*0.2}`
  })
  
  // Progress bar 1
  document.querySelector('.progress-1').style.transform = `scaleX(${progress})`
  
  // Parallax layers
  document.querySelectorAll('[data-speed]').forEach(layer => {
    const speed = parseFloat(layer.dataset.speed) || 0.25
    layer.style.transform = `translate3d(0, ${scroll*speed}px, 0)`
  })
})

// ScrollTo com configuracoes avancadas 1
document.querySelector('#btn-1').addEventListener('click', () => {
  lenis.scrollTo('#section-1', {
    offset: -100,
    duration: 1.1,
    easing: t => 1 - Math.pow(1-t, 3),
    lock: false,
    onComplete: () => console.log('Secao 1 chegou')
  })
})
```

Explicacao tecnica detalhada do exemplo 1:
- lerp 0.060000000000000005 significa que a cada frame o animatedScroll avanca 6.000000000000001% da distancia ate target. Quanto menor, mais pesado e premium.
- wheelMultiplier 0.8500000000000001 controla sensibilidade do mouse. 0.8 e luxo (Apple), 1.2 e esportivo.
- velocity = animated - lastAnimated. Em 60fps, se usuario scrolla rapido, velocity pode chegar a 50-100px por frame.

Topico 20: Como o Lenis calcula velocity e direction para efeitos skew e parallax.

Codigo de exemplo 20:

```js
// Exemplo 20 - Velocity based distortion
import Lenis from 'lenis'
import 'lenis/dist/lenis.css'
import gsap from 'gsap'

const lenis = new Lenis({
  autoRaf: true,
  lerp: 0.25,
  wheelMultiplier: 1.8,
  gestureOrientation: 'vertical',
  smoothTouch: false,
  infinite: false,
  orientation: 'horizontal'
})

lenis.on('scroll', ({scroll, velocity, direction, progress, limit}) => {
  // Efeito 20: skew, scale, opacity baseado em velocity
  const skew = velocity * 0.5
  const scale = 1 + Math.abs(velocity) * 0.001
  document.querySelectorAll('.item-20').forEach(el => {
    el.style.transform = `skewX(${skew}deg) scale(${scale}) translate3d(0, ${scroll*0.1}px, 0)`
    el.style.opacity = `${1 - progress*0.2}`
  })
  
  // Progress bar 20
  document.querySelector('.progress-20').style.transform = `scaleX(${progress})`
  
  // Parallax layers
  document.querySelectorAll('[data-speed]').forEach(layer => {
    const speed = parseFloat(layer.dataset.speed) || 1.2
    layer.style.transform = `translate3d(0, ${scroll*speed}px, 0)`
  })
})

// ScrollTo com configuracoes avancadas 20
document.querySelector('#btn-20').addEventListener('click', () => {
  lenis.scrollTo('#section-20', {
    offset: -100,
    duration: 3.0,
    easing: t => 1 - Math.pow(1-t, 4),
    lock: true,
    onComplete: () => console.log('Secao 20 chegou')
  })
})
```

Explicacao tecnica detalhada do exemplo 20:
- lerp 0.25 significa que a cada frame o animatedScroll avanca 25.0% da distancia ate target. Quanto menor, mais pesado e premium.
- wheelMultiplier 1.8 controla sensibilidade do mouse. 0.8 e luxo (Apple), 1.2 e esportivo.
- velocity = animated - lastAnimated. Em 60fps, se usuario scrolla rapido, velocity pode chegar a 50-100px por frame.
- direction = Math.sign(velocity). 1 = descendo, -1 = subindo. Usado para hide/show header.
- progress = animated / limit. 0 = topo, 1 = fim. Usado para progress bar, shader, etc.
- infinite false quando true, quando animated ultrapassa limit, faz modulo e volta pro comeco.
- orientation horizontal usa scrollLeft em vez de scrollTop.
