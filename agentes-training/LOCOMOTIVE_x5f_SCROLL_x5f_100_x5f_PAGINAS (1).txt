
================================================================================
LOCOMOTIVE SCROLL - ENGENHARIA REVERSA TOTAL - v4 vs v5 (2026)
Versão: v5.0.1 (Jan 2026) - Reescrita total em cima do Lenis - 9.4kB gzipped
Site: scroll.locomotive.ca
================================================================================

O QUE É:
Locomotive Scroll é smooth scroll + detecção de elementos na viewport + parallax.
Foi o padrão ouro 2020-2024. Em 2025, v5 foi reescrita em cima do Lenis (engine moderna).

v4 vs v5:
v4: usava transform: translate3d no container, precisava data-scroll-container, data-scroll-section, bugava com fixed, pesado
v5: usa Lenis por baixo, não usa transform hack, sem wrappers obrigatórios, 9.4kB, TypeScript, muito mais performático, sem CSS obrigatório

ATUALMENTE (2026):
- v5 é recomendada para projetos novos
- v4 ainda usada em sites antigos, mas em desuso
- Locomotive Scroll v5 + GSAP ScrollTrigger é combo, mas ScrollSmoother do GSAP está substituindo

INSTALAÇÃO v5:
npm install locomotive-scroll
import LocomotiveScroll from 'locomotive-scroll'
import 'locomotive-scroll/dist/locomotive-scroll.css' // opcional

INSTALAÇÃO v4 (legado):
npm install locomotive-scroll@4
import LocomotiveScroll from 'locomotive-scroll'

================================================================================
1. LOCOMOTIVE SCROLL v5 - API COMPLETA (ATUAL)
================================================================================

Inicialização básica v5:
import LocomotiveScroll from 'locomotive-scroll'

const scroll = new LocomotiveScroll({
  lenisOptions: {
    duration: 1.2, // duração do lerp
    smoothWheel: true, // smooth no wheel
    smoothTouch: false, // smooth no touch (false para não bugar mobile)
    gestureOrientation: "vertical", // "vertical" | "horizontal" | "both"
  }
})

// Métodos:
scroll.scrollTo(target, { offset: 0, duration: 1, easing: (t)=>t, immediate: false, lock: false, onComplete: ()=>{} })
scroll.start()
scroll.stop()
scroll.destroy()
scroll.update() // recalcula após mudar DOM
scroll.on('scroll', (instance) => { console.log(instance.scroll, instance.progress) })

Atributos HTML v5:
data-scroll - marca elemento para detecção
data-scroll-speed="0.5" - velocidade parallax (0.5 = mais lento, 2 = mais rápido, negativo = oposto)
data-scroll-direction="horizontal" - direção

Exemplo v5 parallax:
<div data-scroll data-scroll-speed="0.5">Move mais devagar (parallax)</div>
<div data-scroll data-scroll-speed="2">Move 2x mais rápido</div>
<div data-scroll data-scroll-speed="-0.5">Move oposto</div>

Scroll progress:
scroll.on('scroll', ({scroll, progress}) => {
  // scroll = px atual
  // progress = 0-1
})

Com GSAP ScrollTrigger + Locomotive v5 (scrollerProxy):
import gsap from 'gsap'
import ScrollTrigger from 'gsap/ScrollTrigger'
gsap.registerPlugin(ScrollTrigger)

const locoScroll = new LocomotiveScroll()

locoScroll.on('scroll', ScrollTrigger.update)

ScrollTrigger.scrollerProxy(document.body, {
  scrollTop(value){
    if(arguments.length){
      locoScroll.scrollTo(value, {immediate: false})
    }
    return locoScroll.scroll // ou instance.scroll
  },
  getBoundingClientRect(){
    return {top:0, left:0, width: window.innerWidth, height: window.innerHeight}
  }
})

ScrollTrigger.addEventListener('refresh', () => locoScroll.update())
ScrollTrigger.refresh()

React + Locomotive v5:
import { useEffect, useRef } from 'react'
import LocomotiveScroll from 'locomotive-scroll'

export function useLocomotive(){
  const scrollRef = useRef(null)
  useEffect(()=>{
    const scroll = new LocomotiveScroll({
      lenisOptions: { duration: 1.2, smoothWheel: true }
    })
    return () => scroll.destroy()
  },[])
}

2. LOCOMOTIVE SCROLL v4 - API COMPLETA (LEGADO - AINDA MUITO USADO)
================================================================================

Inicialização v4:
const scroll = new LocomotiveScroll({
  el: document.querySelector('[data-scroll-container]'),
  smooth: true,
  smoothMobile: false,
  smoothTablet: false,
  direction: 'vertical', // 'vertical' | 'horizontal'
  gestureDirection: 'vertical',
  reloadOnContextChange: true,
  lerp: 0.1, // suavização, 0-1, quanto menor mais suave (0.1 padrão)
  multiplier: 1, // velocidade do scroll
  firefoxMultiplier: 50,
  touchMultiplier: 2,
  tablet: { smooth: true, direction: 'vertical', gestureDirection: 'vertical', breakpoint: 1024 },
  smartphone: { smooth: false }
})

HTML obrigatório v4:
<div data-scroll-container>
  <div data-scroll-section>
    <div data-scroll data-scroll-speed="2">Parallax</div>
  </div>
</div>

Atributos v4 - TODOS:
data-scroll - detecta elemento
data-scroll-container - container principal (só 1)
data-scroll-section - seção (para performance e detecção)
data-scroll-speed="2" - parallax speed, -10 a 10, negativo inverte
  speed 0 = fixo, 1 = normal, 2 = 2x rápido, -1 = oposto
data-scroll-direction="horizontal" - direção do parallax
data-scroll-position="top" | "bottom" - onde parallax começa
data-scroll-delay="0.5" - delay do parallax (0-1)
data-scroll-repeat - repete evento quando entra/sai várias vezes
data-scroll-call="functionName" - chama função quando entra na viewport
data-scroll-offset="10%, 10%" - offset de detecção "top, bottom"
data-scroll-sticky - sticky element
data-scroll-target="#target" - target custom
data-scroll-class="is-inview" - classe quando entra (padrão is-inview)

Exemplos v4:

1. Parallax básico:
<h1 data-scroll data-scroll-speed="1">Título normal</h1>
<h1 data-scroll data-scroll-speed="2">Título rápido</h1>
<h1 data-scroll data-scroll-speed="-1">Título inverso</h1>

2. Reveal quando entra:
<div data-scroll data-scroll-class="is-inview" data-scroll-repeat>
  .is-inview { opacity: 1; transform: translateY(0) }
</div>

3. Call function:
<div data-scroll data-scroll-call="myFunction" data-scroll-repeat></div>
scroll.on('call', (func, way, obj) => {
  if(func === 'myFunction'){
    if(way === 'enter') console.log('entrou', obj.el)
    else console.log('saiu')
  }
})

4. Sticky:
<div data-scroll data-scroll-sticky data-scroll-target="#fixed-target">Fixa</div>

5. Horizontal dentro de vertical:
<div data-scroll-container>
  <div data-scroll-section data-scroll-direction="horizontal">
    <div data-scroll data-scroll-speed="2">Horizontal parallax</div>
  </div>
</div>

Eventos v4:
scroll.on('scroll', (obj) => {
  console.log(obj.scroll.y) // scroll atual
  console.log(obj.limit.y) // limite
  console.log(obj.currentElements) // elementos visíveis
})

Métodos v4:
scroll.update() // após mudar DOM
scroll.scrollTo(target, { offset: 0, duration: 1000, easing: [0.25,0,0.35,1], disableLerp: false, callback: ()=>{} })
scroll.start()
scroll.stop()
scroll.destroy()

CSS necessário v4:
html.has-scroll-smooth { overflow: hidden }
html.has-scroll-dragging { user-select: none }
.has-scroll-smooth body { overflow: hidden }
.has-scroll-smooth [data-scroll-container] { min-height: 100vh }

================================================================================
3. COMPARATIVO v4 vs v5 vs LENIS vs GSAP SCROLLSMOOTHER
================================================================================

v4:
- Bundle: ~12.1kB gzipped
- Engine: Virtual Scroll + transform hack
- Wrappers: precisa data-scroll-container + data-scroll-section
- Fixed: buga com position:fixed, precisa data-scroll-sticky
- Mobile: problemático, precisa desabilitar smooth
- Performance: média, transform em container inteiro

v5:
- Bundle: 9.4kB gzipped
- Engine: Lenis (moderna, usa lerp nativo)
- Wrappers: não precisa, funciona em body
- Fixed: funciona nativo, sem hack
- Mobile: melhor, smoothTouch opcional
- Performance: alta, 60fps
- API: simplificada

Lenis (puro, sem Locomotive):
- Bundle: 4.5kB
- Só smooth scroll, sem parallax/data-scroll
- Mais performático e simples
- Recomendado se só quer smooth, sem parallax

GSAP ScrollSmoother:
- Bundle: ~15kB (com ScrollTrigger)
- Engine: próprio, integrado com ScrollTrigger
- Features: smooth + parallax via data-speed/data-lag + pin + ScrollTrigger nativo
- Melhor para quem já usa GSAP
- Substitui Locomotive em projetos GSAP

RECOMENDAÇÃO 2026:
- Projeto novo sem GSAP? Use Lenis puro (mais leve) ou Locomotive v5 se precisa parallax fácil
- Projeto com GSAP? Use ScrollSmoother, esqueça Locomotive
- Projeto legado? Mantenha v4, mas planeje migrar para v5 ou ScrollSmoother

================================================================================
4. MIGRAÇÃO v4 -> v5
================================================================================

Antes v4:
<div data-scroll-container>
  <div data-scroll-section>
    <div data-scroll data-scroll-speed="2">Oi</div>
  </div>
</div>
const scroll = new LocomotiveScroll({ el: document.querySelector('[data-scroll-container]'), smooth: true })

Depois v5:
<div data-scroll data-scroll-speed="2">Oi</div>
const scroll = new LocomotiveScroll()

Removido em v5:
- data-scroll-container (não precisa)
- data-scroll-section (não precisa)
- data-scroll-sticky (fixed funciona nativo)
- data-scroll-call (use IntersectionObserver ou ScrollTrigger)
- data-scroll-repeat (use callback)
- data-scroll-class (use CSS + JS)

Novo em v5:
- lenisOptions
- scrollTo com objeto
- Evento 'scroll' com {scroll, progress}
