GSAP.to() assinatura completa:
gsap.to(targets: Selector|Object|Array, vars: {
  // propriedades animáveis: qualquer número
  x, y, z, xPercent, yPercent, rotation, rotationX, rotationY, scale, scaleX, scaleY, skewX, skewY,
  opacity, backgroundColor, color, width, height, top, left,
  // vars especiais GSAP
  duration: number (segundos, default 0.5)
  delay: number
  repeat: number | -1
  repeatDelay: number
  yoyo: boolean
  yoyoEase: string|function
  ease: string|function
  stagger: number | {each, from, grid, axis, amount, ease}
  overwrite: boolean | "auto" | "none" | "all" | "concurrent"
  immediateRender: boolean
  runBackwards: boolean
  // callbacks
  onStart, onUpdate, onComplete, onRepeat, onInterrupt
  onStartParams, onUpdateParams, etc
  callbackScope
})

Targets aceitos:
- string ".box"
- element document.querySelector
- array de elements
- objeto JS puro {myVal:0}
- array de objetos

Exemplos nível hard:

// 1. Stagger em grid 10x10 com from center e amount total
gsap.to(".grid-item", {
  scale: 0,
  duration: 0.6,
  stagger: {
    amount: 1,
    grid: [10,10],
    from: "center",
    axis: "y",
    ease: "power2.inOut"
  }
})

// 2. Modifiers - intercepta valor antes de aplicar
gsap.to(".box", {
  x: 500,
  modifiers: {
    x: gsap.utils.unitize(x => parseFloat(x) % 300, "px") // loop manual
  }
})

// 3. Function-based values - cada elemento tem valor diferente
gsap.to(".box", {
  x: (index, target) => index * 100,
  y: (index) => Math.sin(index) * 50
})

// 4. Animar atributo SVG
gsap.to("circle", {attr: {r: 50, cx: 100}, duration: 1})

// 5. Animar CSS variável
gsap.to(".box", {"--my-color": "red", duration: 1})

PARTE B - GSAP.UTILS - 22 FUNÇÕES - ENGENHARIA REVERSA MATEMÁTICA
================================================================================
Cada util abaixo é puro JS, 0 dependência, tree-shakeable.

1. clamp(min,max,val) -> number
   Impl interna: Math.min(max, Math.max(min, val))
   Caso real: limitar arraste
   let clamped = gsap.utils.clamp(0, 500, draggableX)

2. mapRange(inMin,inMax,outMin,outMax,value) -> number
   Fórmula: outMin + (outMax-outMin)*((value-inMin)/(inMax-inMin))
   Caso real: parallax baseado em mouse
   window.addEventListener("mousemove", e => {
     let rot = gsap.utils.mapRange(0, innerWidth, -15, 15, e.clientX)
     gsap.to(".card", {rotationY: rot, duration: 0.8})
   })

3. normalize(min,max,val) -> 0-1
   Impl: (val-min)/(max-min)

4. interpolate(from,to,progress) -> any
   Suporta: number, string com número, cor hex/rgb/hsl, array, objeto
   Ex cor: interpolate("#ff0000","#0000ff",0.5) => "rgba(128,0,128,1)"
   Ex objeto: interpolate({x:0,y:0},{x:100,y:100},0.25)

5. snap(snapTo, value)
   Se snapTo é número: Math.round(value/snapTo)*snapTo
   Se array: encontra mais próximo
   Uso: gsap.to(el, {x: 100, modifiers: {x: x=>gsap.utils.snap(20,x)}})

6. wrap(min,max,val) -> loop
   Fórmula: min + ((val-min) % (max-min + (max-min<0?0:0))) com correção negativa
   Uso: carrossel infinito

7. wrapYoyo(min,max,val) -> ping-pong loop

8. random(min,max, snap?, returnFunction?)
   Pode retornar função se último arg true
   let randomX = gsap.utils.random(-100,100,5,true) // retorna função que gera random

9. distribute({base, amount, from, grid, axis, ease})
   Retorna função (index, target, arr) => value
   Implementação interna usa mapRange + ease

10. pipe(...funcs)
    funcs.reduce((v,f)=>f(v), initial)

11. unitize(func, unit) => (val) => func(val)+unit
12. toArray(any) => limpa NodeList, string, etc
13. selector(context) => scoped querySelectorAll
14. shuffle(arr) => Fisher-Yates
15. splitColor(color, toHSL?) => [r,g,b,a]
16. getUnit(str) => extrai "px","%","em"
17. checkPrefix(prop) => prefixo vendor
18. clamp com currying: se passar só min,max retorna função

EXEMPLOS COMBINADOS PROFISSIONAIS:

// Mapear scroll para escala com clamp + snap
let scaleMap = gsap.utils.pipe(
  v => gsap.utils.mapRange(0,1000,0.5,2,v),
  v => gsap.utils.clamp(0.5,2,v),
  v => gsap.utils.snap(0.1,v)
)

// Distribuição aleatória controlada
gsap.to(".dot", {
  x: () => gsap.utils.random(-200,200),
  y: () => gsap.utils.random(-200,200),
  duration: 1,
  stagger: gsap.utils.distribute({base:0, amount:0.5, from:"random"})
})

--- SCROLLTRIGGER ---
É um plugin que cria um ScrollTrigger instance por trigger. Internamente usa IntersectionObserver + scroll listener otimizado.

Propriedades completas:
trigger: Element|string
start: "top bottom" | "top 80%" | "center center" | "top+=100 bottom" | function
end: similar, pode ser "+=500", "bottom top", etc
scrub: false | true | number (suavização em segundos)
pin: false | true | Element | selector
pinSpacing: true | false | "margin"
anticipatePin: number
markers: true | {startColor, endColor, fontSize}
toggleActions: "play pause resume reset" (4 estados: onEnter, onLeave, onEnterBack, onLeaveBack)
toggleClass: string | {targets, className}
onEnter, onLeave, onEnterBack, onLeaveBack, onUpdate, onToggle, onRefresh
snap: number | array | {snapTo, duration, ease}
scroller: Element|string (custom scroll container)
horizontal: boolean
invalidateOnRefresh: boolean
refreshPriority: number

EXEMPLOS AVANÇADOS SCROLLTRIGGER:

--- FLIP ---
FLIP = First, Last, Invert, Play. Captura estado inicial e final e anima diferença.

Fluxo:
1. getState (First)
2. Muda DOM (Last)
3. from(state) calcula Invert e faz Play

API:
Flip.getState(targets, {props: "x,y,width,height,opacity", simple:true})
Flip.from(state, {
  duration, ease, absolute:true, absoluteOnLeave, stagger, nested, 
  spin:false, simple:true,
  onEnter: el => animação de entrada,
  onLeave: el => animação de saída,
  onComplete
})
Flip.to(state, {...}) // anima para estado salvo
Flip.fit(from, to, {...})

EXEMPLOS FLIP:

1. Shuffle grid:

2. Modal que expande do botão:

function filter(cat){
  let state = Flip.getState(".item")

1. O QUE É GSAP POR DENTRO
================================================================================
GSAP não é "uma biblioteca de animação". É um runtime de interpolação de propriedades
com ticker centralizado de 60fps (usa requestAnimationFrame otimizado).

O que ele anima? QUALQUER COISA QUE SEJA UM NÚMERO OU STRING COM NÚMERO.

================================================================================
2. ARQUITETURA INTERNA E POR QUE É TÃO RÁPIDO
================================================================================
Ticker único: GSAP tem um ticker global. Todos tweens são atualizados em um único loop,
evitando múltiplos requestAnimationFrame. 60% mais rápido que animações CSS separadas.

Cache de transform: Ele não escreve `transform: translateX() rotate()` separado. Ele compõe
uma matrix. Lê uma vez, escreve uma vez.

Auto-acceleration: Detecta se você está animando x/y e automaticamente usa translate3d
para forçar GPU layer.

PropTweens: Internamente cada propriedade vira um PropTween linkado em lista ligada.
Ex: gsap.to(el, {x:100, opacity:0}) => cria 2 PropTweens.

Lazy Rendering: Alterações são enfileiradas e flush no final do tick para evitar layout thrashing.

3. NÚCLEO - CORE API - CADA MÉTODO DISSECADO
================================================================================

--- gsap.to() ---
Utilidade: Anima DE onde está PARA um destino.
Possibilidade: Qualquer propriedade.
Vantagem: Estado inicial automático.
Código:
gsap.to(".box", {
  x: 500,
  y: 100,
  rotation: 360,
  scale: 1.5,
  duration: 2,
  ease: "power2.inOut",
  repeat: -1,
  yoyo: true,
  delay: 0.5
});

// Objeto JS puro (contador)
let obj = {score: 0}
gsap.to(obj, {
  score: 100,
  duration: 3,
  onUpdate: () => console.log(obj.score)
});

Propriedades especiais:
- duration: segundos
- delay: segundos
- repeat: número ou -1 infinito
- yoyo: true faz ir e voltar
- repeatDelay: delay entre repeats
- ease: string ou função
- stagger: atraso entre múltiplos alvos
- overwrite: como lidar com conflitos ("auto", true, false, "none")
- immediateRender: false para from()
- onComplete, onUpdate, onStart, onRepeat: callbacks
- onCompleteParams, etc

--- gsap.from() ---
Utilidade: Anima DE um estado PARA onde está.
Código:
gsap.from(".box", {x: -500, opacity: 0, duration: 1})

--- gsap.fromTo() ---
Utilidade: Controle total início e fim. Mais performático, sem leitura de estado inicial.
Código:
gsap.fromTo(".box", 
  {x: 0, opacity: 0},
  {x: 500, opacity: 1, duration: 1}
)

--- gsap.set() ---
Utilidade: Define instantaneamente sem animação. duration 0.
Código: gsap.set(".box", {x: 100, opacity: 0.5})

--- gsap.quickTo() e quickSetter() ---
Utilidade: ULTRA PERFORMANCE para mousemove, scroll. Cria função otimizada que não cria novo tween.
Código:
// 10x mais rápido para seguir mouse
let xTo = gsap.quickTo(".cursor", "x", {duration: 0.6, ease: "power3"})
let yTo = gsap.quickTo(".cursor", "y", {duration: 0.6, ease: "power3"})
window.addEventListener("mousemove", e => {
  xTo(e.clientX)
  yTo(e.clientY)
})

--- gsap.context() ---
Utilidade: Escopo para React/Vue, permite revert limpo.
Código:
let ctx = gsap.context(() => {
  gsap.to(".box", {x: 100})
}, ".container")
// depois
ctx.revert() // mata tudo criado dentro

--- gsap.matchMedia() ---
Utilidade: Animações responsivas nativas.
Código:
let mm = gsap.matchMedia()
mm.add("(min-width: 800px)", () => {
  gsap.to(".box", {x: 500})
})
mm.add("(max-width: 799px)", () => {
  gsap.to(".box", {x: 100})
})

--- gsap.getProperty(), getTweensOf(), isTweening(), killTweensOf() ---
Código:
gsap.getProperty(".box", "x") // pega valor atual parseado
gsap.killTweensOf(".box") // mata animações

4. TIMELINE - A ALMA DO GSAP
================================================================================
Timeline é um container de tweens com controle de tempo absoluto. É onde GSAP destrói
todas as outras libs.

Criação:
let tl = gsap.timeline({
  defaults: {duration: 1, ease: "power2.out"},
  repeat: -1,
  repeatDelay: 1,
  yoyo: true,
  onComplete: () => {}
})

Position Parameter (o segredo):
- "+=1" => 1 segundo DEPOIS do fim do anterior
- "-=0.5" => 0.5 segundos ANTES do fim do anterior (overlap)
- "<" => início do anterior
- "> " => fim do anterior (default)
- "<0.2" => 0.2s depois do início do anterior
- 2 => tempo absoluto 2s

Código completo:
let tl = gsap.timeline()
tl.to(".box1", {x: 100})
  .to(".box2", {x: 100}, "-=0.5") // overlap 50%
  .to(".box3", {x: 100}, "<") // junto com box2
  .addLabel("meio")
  .to(".box4", {x: 100}, "meio+=0.5")
  .from(".texto", {opacity: 0, y: 20})

Controle:
tl.play()
tl.pause()
tl.reverse()
tl.seek(2) // vai para 2s
tl.progress(0.5) // 50%
tl.timeScale(2) // 2x velocidade
tl.restart()

Nesting:
let master = gsap.timeline()
master.add(childTimeline1)
      .add(childTimeline2, "+=1")

Utilidade infinita: Intro de site, storytelling, onboarding.

6. GSAP.UTILS - 22 UTILITÁRIOS PUROS (NÃO PRECISA REGISTRAR)
================================================================================
Esses são funções matemáticas puras, usáveis fora de tween.

1. clamp(min, max, value)
   Limita valor.
   gsap.utils.clamp(0, 100, 150) => 100
   Uso: limitar drag, scroll.

2. mapRange(inMin, inMax, outMin, outMax, value)
   Mapeia um range para outro.
   // scroll 0-1000 vira opacity 0-1
   let opacity = gsap.utils.mapRange(0, 1000, 0, 1, scrollY)

3. normalize(min, max, value)
   Mapeia para 0-1.
   gsap.utils.normalize(0, 1000, 500) => 0.5

4. interpolate(start, end, progress)
   Interpola. Aceita números, cores, arrays, objetos!
   gsap.utils.interpolate(0, 100, 0.5) => 50
   gsap.utils.interpolate("red", "blue", 0.5) => cor roxa
   gsap.utils.interpolate({x:0,y:0}, {x:100,y:100}, 0.5) => {x:50,y:50}

5. snap(increment | array, value)
   Gruda em grade.
   gsap.utils.snap(10, 23) => 20
   gsap.utils.snap([0,50,100], 60) => 50 (mais próximo)

6. wrap(min, max, value)
   Loop infinito. 101 vira 1 se range 0-100.
   gsap.utils.wrap(0, 100, 150) => 50
   Uso: carrossel infinito.

7. wrapYoyo(min, max, value)
   Wrap que vai e volta.

8. random(min, max, snapIncrement?)
   Random. Pode snap.
   gsap.utils.random(0, 100)
   gsap.utils.random(0, 100, 5) => múltiplo de 5
   gsap.utils.random(["red","blue"]) => sorteia do array

9. splitColor(color)
   Quebra cor em [r,g,b,a].
   gsap.utils.splitColor("rgba(255,0,0,0.5)") => [255,0,0,0.5]

10. toArray(selector)
    Converte qualquer coisa em array limpo.
    gsap.utils.toArray(".box") => [...elements]

11. distribute(config)
    Distribui valores com stagger avançado.
    let distribute = gsap.utils.distribute({base: 0, amount: 1, from: "center", grid: "auto", axis: "y", ease: "power1"})
    // uso em stagger:
    gsap.to(".box", {x: 100, stagger: {each: 0.1, from: "center", grid: [3,3]}})

12. pipe(...functions)
    Encadeia funções: saída de uma vira entrada da próxima.
    let clampAndSnap = gsap.utils.pipe(
      (v) => gsap.utils.clamp(0,100,v),
      (v) => gsap.utils.snap(10,v)
    )

13. unitize(func, unit)
    Adiciona unidade.
    let addPx = gsap.utils.unitize(v => v*2, "px")

14. selector(scope)
    Cria seletor com escopo.
    let q = gsap.utils.selector(".container")
    q(".box") => só dentro de .container

15. shuffle(array)
    Embaralha array.

16. getUnit(value)
    Pega unidade: getUnit("100px") => "px"

17. checkPrefix(prop)
    Detecta prefixo vendor.

18. getProperty
    (alias para gsap.getProperty)

... e mais.

Exemplo mestre combinando:
let mapper = gsap.utils.pipe(
  (v) => gsap.utils.mapRange(0, window.innerWidth, -100, 100, v),
  (v) => gsap.utils.clamp(-100, 100, v),
  (v) => gsap.utils.snap(1, v)
)
window.addEventListener("mousemove", e => {
  gsap.to(".box", {x: mapper(e.clientX), duration: 0.5})
})

11. PERFORMANCE E OTIMIZAÇÃO EXTREMA
================================================================================
1. Use transform (x,y) em vez de left/top - 10x mais rápido
2. Use gsap.set() para estado inicial, não CSS + from()
3. Use fromTo() quando souber início e fim - evita leitura de layout
4. Use quickTo/quickSetter para mousemove/scroll
5. Evite animar width/height se puder usar scale
6. Use will-change: só quando GSAP já coloca automaticamente
7. Limite ScrollTriggers: use batch, não 100 triggers separados
8. Use overwrite: "auto" para evitar conflitos
9. Para muitos elementos (1000+), use stagger e force3D:false se não precisar
10. Use Flip com absolute:true para grids

LagSmoothing:
gsap.ticker.lagSmoothing(500,33) // tolera 500ms lag, 33ms threshold
