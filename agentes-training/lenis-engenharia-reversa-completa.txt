1. INTRODUÇÃO E FILOSOFIA
================================================================================
Lenis significa "suave" em latim. Criado pela Darkroom Engineering (ex-Studio Freight).
Não é um scroll hijack burro. Ele NÃO cria um div com transform translate.

Princípio 1: Roda em cima do scroll NATIVO.
Ele deixa o browser continuar com overflow: auto nativo. Ele apenas atrasa o valor
targetScroll até animatedScroll usando lerp/duration. Por isso sticky, anchor, find-in-page, acessibilidade continuam funcionando.

Princípio 2: Single RAF.
Um único requestAnimationFrame. Se você usa GSAP, ele não cria outro loop. Você injeta lenis.raf(time) no ticker do GSAP. Um frame budget.

Princípio 3: Virtual Scroll Layer.
Wheel, touch, keyboard, etc são normalizados em virtual-scroll.ts para um deltaY/X consistente. O Lenis nunca lê direto do evento wheel sem passar por prevent/virtualScroll/allowNestedScroll.

Manifesto: Locomotive Scroll morreu porque era pesado, bugava sticky e tinha transform scroll. Lenis nasceu para ser 3kb, sem dependências, e fazer 1 coisa muito bem.

3. ARQUITETURA NUCLEAR - O FLUXO DE DADOS
================================================================================
[EVENTO NATIVO] -> [VirtualScroll] -> [Lenis.onVirtualScroll] -> [targetScroll += delta]
                                                                 |
                                                                 v
[RAF TICK] -> lenis.raf(time) -> Animate.advance(time) -> animatedScroll = lerp(animatedScroll, targetScroll)
                                                                 |
                                                                 v
[Dimensions] calcula limit -> animatedScroll clamp 0..limit -> wrapper.scrollTop = animatedScroll (se root=window) ou wrapper.scrollTo
                                                                 |
                                                                 v
[Emit] -> 'scroll' event com {scroll, limit, velocity, direction, progress} -> seu código, GSAP, parallax

O pulo do gato: animatedScroll NUNCA vai direto pro DOM via transform. Ele seta o scrollTop real do scroller. Por isso o browser acha que é scroll nativo.

Dois modos de animação:
A) lerp mode: se options.lerp está definido (!== undefined), ignora duration/easing. Usa lerp puro: animated += (target - animated) * lerp
B) duration mode: se lerp undefined, usa Animate com easing e duration em segundos. É um tween baseado em tempo, não em frame.

Velocity é derivada: velocity = currentAnimated - lastAnimated
Direction: 1 = descendo / direita, -1 = subindo / esquerda (em vertical/horizontal)

infinite: quando animated ultrapassa limit, reseta para 0 ou limit mantendo continuidade, criando loop infinito. Exige syncTouch true no touch.

4. CLASSE LENIS (lenis.ts) - DISSECAÇÃO LINHA A LINHA
================================================================================
Constructor(options: LenisOptions):
- merge options com defaults:
  wrapper = window
  content = document.documentElement
  eventsTarget = wrapper
  smoothWheel = true
  lerp = 0.1 (default novo é duration 1.2, mas se usuário passa lerp usa lerp)
  duration = 1.2
  easing = t => Math.min(1, 1.001 - Math.pow(2, -10*t)) // expo out
  orientation = vertical
  gestureOrientation = vertical
  smoothTouch = false -> DESLIGADO por padrão para performance mobile
  syncTouch = false
  syncTouchLerp = 0.075
  touchInertiaExponent = 1.7
  wheelMultiplier = 1
  touchMultiplier = 1
  infinite = false
  autoResize = true
  prevent = undefined
  virtualScroll = undefined
  overscroll = true
  autoRaf = false
  anchors = false
  autoToggle = false
  allowNestedScroll = false
  naiveDimensions = false
  stopInertiaOnNavigate = false

- this.options = options merged
- this.emitter = new Emitter()
- this.dimensions = new Dimensions(wrapper, content, {autoResize, ...})
- this.virtualScroll = new VirtualScroll(eventsTarget, {wheelMultiplier, touchMultiplier, ...})
- this.animate = new Animate() -> gerencia valor atual
- this.animatedScroll = 0
- this.targetScroll = 0
- this.actualScroll = 0
- this.velocity = 0
- this.isStopped = false
- this.isScrolling = false

Métodos internos chave:
init():
  adiciona classes: this.rootElement.classList.add('lenis'), 'lenis-smooth', 'lenis-scrolling' etc
  liga events: virtualScroll.on('scroll', this.onVirtualScroll)
  dimensions.on('resize', this.onResize)
  se autoRaf true: inicia raf interno via requestAnimationFrame loop
  se anchors: liga click delegation em document para a[href^="#"]
  se autoToggle: liga MutationObserver? Na verdade usa CSS transition-behavior check

onVirtualScroll({deltaX, deltaY, event}):
  se this.isStopped return
  se options.prevent(node) return -> checa event path, se retornar true, não suaviza
  se options.virtualScroll(e) === false return
  se !options.overscroll e estamos no limite e tentando passar, return false (deixa browser fazer bounce)
  se gestureOrientation === vertical e deltaY ===0 return; se horizontal idem; se both deixa ambos
  se allowNestedScroll: percorre event.composedPath() e verifica se algum elemento tem overflow scroll e está no meio do scroll, se sim deixa nativo
  calcula delta = orientation === vertical ? deltaY : deltaX
  multiplica por wheelMultiplier ou touchMultiplier dependendo do tipo
  this.targetScroll += delta
  this.targetScroll clamp 0..limit se !infinite

raf(time):
  this.time = time
  this.dimensions.resize() se dirty
  const deltaTime = time - lastTime
  se isScrolling: this.animate.advance(time)
  se lerp mode: this.animatedScroll = lerp(this.animatedScroll, this.targetScroll, lerp * correção deltaTime)
  senão: this.animatedScroll = this.animate.value
  se infinite: normaliza animatedScroll para dentro do limit
  clamp animated se !infinite
  this.actualScroll = this.rootElement.scrollTop/scrollLeft (leitura real)
  this.velocity = this.animatedScroll - lastAnimatedScroll
  this.direction = Math.sign(velocity) ou mantém último
  escreve no DOM: rootElement.scrollTo({top: animatedScroll}) se vertical
  emite 'scroll' event
  se target próximo de animated (dif < 0.1) -> stop scrolling state

scrollTo(target, options?):
  target pode ser: number, string selector, HTMLElement, 'top'|'bottom'|'left'|'right'|'start'|'end'
  resolve:
    se number: targetScroll = number
    se 'top'/'start'/'left': 0
    se 'bottom'/'end'/'right': limit
    se HTMLElement: calcula offsetTop relativo ao content + offset option + scroll-margin CSS respeitado (novo fix #507)
    se string: document.querySelector(string) ou getElementById se começa com # (fix #520 para ids com caracteres especiais)
  options:
    offset: number
    lerp: override lerp
    duration: override duration
    easing: override easing
    immediate: boolean -> se true, seta animated = target direto, sem animação
    lock: boolean -> chama stop() até onComplete
    force: boolean -> mesmo se isStopped, força scroll
    onComplete: callback
    userData: objeto passado no evento scroll
  cria nova animação em this.animate.fromTo(animatedScroll, target, {duration, easing, lerp, onComplete})
  this.targetScroll = target

stop()/start():
  isStopped = true/false
  toggle class 'lenis-stopped'

resize():
  dimensions recalcula limit = content.scrollHeight - wrapper.clientHeight (ou width)
  emite resize?

destroy():
  remove classes
  virtualScroll.destroy()
  dimensions.destroy()
  cancelAnimationFrame
  emitter.destroy()
  remove event listeners anchors

CSS classes gerenciadas:
  .lenis -> no root
  .lenis-smooth -> quando smooth ativo
  .lenis-scrolling -> enquanto está animando
  .lenis-stopped -> quando stop()
  .lenis-smooth [data-lenis-prevent] { overscroll-behavior: contain }

5. MOTOR DE ANIMAÇÃO (animate.ts)
================================================================================
class Animate {
  constructor()
  from, to, current, lerp, duration, easing, time, isRunning

  fromTo(from, to, {lerp, duration, easing, onComplete}):
    this.from = from; this.to = to; this.lerp = lerp; this.duration = duration; this.easing = easing
    this.time = performance.now()
    this.isRunning = true

  advance(time):
    se lerp definido: this.current = lerp(this.current, this.to, this.lerp)
    senão: t = clamp((time - startTime)/(duration*1000), 0,1); eased = easing(t); this.current = from + (to-from)*eased
    QUANTIZE = 10 -> arredonda para detectar fim mais estável em telas 120hz
    se Math.abs(to - current) < 0.01 -> current = to; isRunning = false; onComplete()

  Por que lerp 0.1 é padrão em muitos setups? 0.1 dá inércia suave, 60fps, parece nativo mas com peso. lerp 0.075 é mais pesado. lerp 0.2 é mais rápido.

  Easing default: (t) => Math.min(1, 1.001 - Math.pow(2, -10*t)) -> exponential out, começa rápido e desacelera longo, parece natural.

}

6. DIMENSÕES (dimensions.ts)
================================================================================
class Dimensions:
  wrapper, content, limit, wrapperHeight, contentHeight, etc
  ResizeObserver no content e wrapper se autoResize true
  Método resize():
    wrapperWidth = wrapper === window ? window.innerWidth : wrapper.clientWidth
    wrapperHeight = window ? innerHeight : clientHeight
    contentWidth = content.scrollWidth
    contentHeight = content.scrollHeight
    limit = { x: contentWidth - wrapperWidth, y: contentHeight - wrapperHeight }
  getter limit.y ou limit.x dependendo orientation
  naiveDimensions option: se true, usa getBoundingClientRect em vez de clientHeight, mais caro mas corrige casos com transform

7. VIRTUAL SCROLL (virtual-scroll.ts)
================================================================================
Unifica:
- wheel event: deltaY normalizado (line vs pixel mode). Se event.deltaMode === 1 (line), multiplica por 16? etc
- touch: touchstart -> armazena startY, touchmove -> delta = start - current, touchend -> calcula inércia com touchInertiaExponent
  syncTouch: se true, durante touchmove, já atualiza targetScroll em tempo real, não só no end. Se false, só no wheel.
  syncTouchLerp: lerp usado durante inércia pós-touch
  Inertia: após touchend, calcula velocidade = delta / deltaTime, e projeta target = current + velocity * multiplier^exponent
- keyboard: PageUp, PageDown, Arrow, Space, Home, End -> mapeia para delta
- preventDefault? No código novo, eles só preventDefault se não for input, textarea, contenteditable, etc. Fix do warning IgnoredEventCancel (linha 435) -> só chama preventDefault se evento cancelable

Emite: this.emitter.emit('scroll', {deltaX, deltaY, event})

11. TODAS AS OPÇÕES - ENGENHARIA REVERSA PROFUNDA
================================================================================
wrapper: default window. Se você passa div, vira scroll container custom. Útil para dashboards.
content: default document.documentElement. Se wrapper é div, content deve ser filho direto com height maior.
eventsTarget: onde ouvir wheel/touch. Default wrapper. Pode ser window para capturar global.
smoothWheel: true/false. Se false, wheel vira nativo, só touch suavizado se syncTouch.
lerp vs duration: MUTUAMENTE EXCLUSIVOS. Se definir lerp, duration/easing ignorados. lerp é mais simples e frame-rate dependente mas com correção. duration é time-based, mais consistente.
easing: função t 0..1. Você pode usar de easings.net. Ex: t => 1 - Math.pow(1-t, 3) (cubic out)
orientation: vertical/horizontal. Se horizontal, Lenis usa scrollLeft.
gestureOrientation: vertical/horizontal/both. Se both, usuário pode scrollar nas duas direções com mesmo Lenis? Útil para diagonal.
syncTouch: false por padrão. Se true, mobile tem inércia suave mas pode ser instável iOS <16. Se false, mobile fica nativo (recomendado).
syncTouchLerp: lerp da inércia touch.
touchInertiaExponent: 1.7 default. Maior = mais inércia após soltar dedo.
wheelMultiplier: 1. 0.5 = mais lento, 2 = mais rápido. Truque: use 0.8 para feel premium.
touchMultiplier: idem.
infinite: false. Quando true, quando passa do final volta pro começo. Requer syncTouch true no mobile. Exemplo https://codepen.io/ClementRoche/pen/OJqBLod
autoResize: true. Se false você deve chamar lenis.resize() manual após mudar DOM.
prevent: (node) => boolean. Função que recebe cada node do event path. Se retornar true, aquele scroll não é suavizado. Ex: node => node.closest('.modal') != null
virtualScroll: (data) => boolean/void. Permite modificar delta antes de consumir. Ex: (e) => { e.deltaY *= 0.5 }
overscroll: true. Se false, quando atinge limite, deixa browser fazer bounce nativo.
autoRaf: false. Se true, Lenis cria seu próprio raf loop interno. Se false, você deve chamar lenis.raf(time) manual. Recomendado false se usa GSAP ticker.
anchors: false/true/ScrollToOptions. Se true, intercepta cliques em <a href="#id"> e faz scrollTo suave. Se objeto, usa como options do scrollTo.
autoToggle: false. Se true, Lenis desliga sozinho quando wrapper não tem overflow (ex: página curta). Requer CSS transition-behavior suporte (Chrome 116+, Safari 17.3+)
allowNestedScroll: false. Se true, detecta automaticamente divs scrolláveis dentro e deixa nativo. Custo: percorre DOM a cada wheel, pode dar lag. Melhor usar data-lenis-prevent.
naiveDimensions: false. Se true, cálculo de dimensões mais caro mas mais preciso com transforms.
stopInertiaOnNavigate: false. Se true, para inércia quando clica em link interno.

Atributos HTML:
data-lenis-prevent: previne todo smooth
data-lenis-prevent-wheel: só wheel
data-lenis-prevent-touch: só touch
data-lenis-prevent-vertical / horizontal: direcional

17. PACOTE lenis/snap
================================================================================
snap.ts:
  classe Snap que recebe lenis instance
  options: type mandatory/proximity, velocityThreshold, etc
  Lógica:
    on scroll end (velocity ~0), calcula qual snap point mais próximo
    snap points definidos por elementos com data-lenis-snap ou array manual
    se distance < threshold, chama lenis.scrollTo(snapPoint)
  element.ts: parse data-lenis-snap-align, start, stop

Por que existe? Porque CSS scroll-snap conflita com Lenis. Lenis desativa scroll-snap nativo, então precisa de JS snap.

Uso:
import { Snap } from 'lenis/snap'
const snap = new Snap(lenis, { type: 'mandatory' })

- Locomotive usa transform no content, quebra sticky, quebra acessibilidade, quebra find, precisa de data-scroll attributes. Lenis usa scroll nativo.

21. PERFORMANCE - POR QUE É 60FPS
================================================================================
- Um RAF apenas
- Não lê layout thrashing: lê scrollTop uma vez, escreve uma vez
- Usa transform3d para parallax, não top/left
- ResizeObserver em vez de window resize
- Emitter leve, sem EventEmitter do Node
- QUANTIZE evita micro atualizações
- CSS .lenis-smooth iframe pointer-events none evita reflow em iframes
- syncTouch false por padrão evita custo de touch inertia no mobile

Benchmark: Lenis add <1ms por frame em Lighthouse, vs Locomotive 3-5ms.

================================================================================
22. LIMITAÇÕES REAIS E COMO BURLAR
================================================================================
- Não suporta CSS scroll-snap -> use lenis/snap
- Capado 60fps Safari bug 173434 e 30fps low power mode -> nada a fazer, mas use lerp em vez de duration para parecer suave mesmo 30fps
- Iframe bloqueia wheel -> CSS pointer-events none no iframe quando scrolling, ou overlay div
- position: fixed lag MacOS Safari pre-M1 -> use transform: translate3d(0,0,0) no fixed
- touch events instáveis iOS<16 com syncTouch true -> deixe syncTouch false
- nested scroll precisa config -> use data-lenis-prevent ou allowNestedScroll true (com custo)

23. CÓDIGO FONTE COMENTADO - RECRIAÇÃO MINIMALISTA FUNCIONAL
================================================================================
Abaixo está uma recriação vanilla de ~150 linhas que replica 80% do Lenis, para você entender o núcleo.

```js
// LENIS MINIMAL CLONE - DIDÁTICO
class Animate {
  constructor(){ this.current=0; this.target=0; this.lerp=0.1; this.running=false }

class LenisMini {
  constructor({lerp=0.1, wrapper=window, content=document.documentElement, wheelMultiplier=1}={}){
    this.wrapper=wrapper; this.content=content; this.lerp=lerp; this.wheelMultiplier=wheelMultiplier
    this.target=0; this.current=0; this.limit=0
    this.rafId=null; this.onScrollCbs=[]
    this.resize()
    this.wrapper.addEventListener('wheel', this.onWheel.bind(this), {passive:false})
    window.addEventListener('resize', ()=>this.resize())
    this.raf()
  }
  resize(){
    const h = this.wrapper===window?window.innerHeight:this.wrapper.clientHeight
    const ch = this.content.scrollHeight
    this.limit = ch - h
  }
  onWheel(e){
    e.preventDefault()
    this.target += e.deltaY * this.wheelMultiplier
    this.target = Math.max(0, Math.min(this.target, this.limit))
  }
  raf(){
    this.current += (this.target - this.current)*this.lerp
    if(Math.abs(this.target-this.current)<0.01) this.current=this.target
    if(this.wrapper===window) window.scrollTo(0,this.current)
    else this.wrapper.scrollTop=this.current
    this.onScrollCbs.forEach(cb=>cb({scroll:this.current, limit:this.limit, progress:this.current/this.limit}))
    this.rafId=requestAnimationFrame(()=>this.raf())
  }
  on(event, cb){ if(event==='scroll') this.onScrollCbs.push(cb) }
  scrollTo(target){ 
    if(typeof target==='string'){ 
      const el=document.querySelector(target); 
      if(el) this.target=el.offsetTop 
    } else this.target=target
  }
  destroy(){ cancelAnimationFrame(this.rafId) }
}
```

```ts
export class Animate {
  from: number; to: number; value: number; lerp: number; duration: number; easing: (t:number)=>number
  currentTime: number; isRunning: boolean
  constructor(){ this.value=0; this.isRunning=false }
  fromTo(from:number,to:number,{lerp,duration,easing,onComplete}:any){
    this.from=from; this.to=to; this.value=from
    this.lerp=lerp; this.duration=duration; this.easing=easing||(t=>t)
    this.currentTime=0; this.isRunning=true; this.onComplete=onComplete
  }
  advance(time:number){
    if(this.lerp){
      this.value = lerp(this.value, this.to, this.lerp)
      if(Math.abs(this.to-this.value)<0.01){ this.value=this.to; this.isRunning=false; this.onComplete?.() }
    } else {
      const t = Math.min(1, (time - this.currentTime)/(this.duration*1000))
      this.value = this.from + (this.to-this.from)*this.easing(t)
      if(t>=1){ this.isRunning=false; this.onComplete?.() }
    }
  }
}
```
