CAPITULO 1: O QUE E LENIS E POR QUE MATOU O LOCOMOTIVE
================================================================================
Lenis = smooth em latim. Criado pela Darkroom Engineering (ex-Studio Freight).
Nao e scroll hijack burro. Ele NAO cria div com transform translate.

Principio 1: Roda em cima do scroll NATIVO. Deixa browser com overflow auto nativo. So atrasa targetScroll ate animatedScroll usando lerp/duration. Por isso sticky, anchor, find-in-page, acessibilidade continuam.

Principio 2: Single RAF. Um unico requestAnimationFrame. Se usa GSAP, injeta lenis.raf(time) no ticker do GSAP. Um frame budget.

Principio 3: Virtual Scroll Layer. Wheel, touch, keyboard normalizados em virtual-scroll.ts para deltaY/X consistente. Nunca le direto do wheel sem passar por prevent/virtualScroll/allowNestedScroll.

Manifesto: Locomotive morreu porque era pesado, bugava sticky e tinha transform. Lenis nasceu para ser 3kb, sem dependencias, e fazer 1 coisa muito bem.

Instalacao:
npm i lenis
import Lenis from 'lenis'
import 'lenis/dist/lenis.css'

Metodos internos:
init(): adiciona classes lenis, lenis-smooth, liga virtualScroll.on('scroll'), dimensions.on('resize'), anchors click delegation, autoRaf loop

onVirtualScroll({deltaX, deltaY, event}):
  se isStopped return
  se prevent(node) return
  se virtualScroll(e) === false return
  se allowNestedScroll: percorre composedPath e verifica se algum elemento tem overflow scroll e esta no meio, se sim deixa nativo
  gestureOrientation filter
  overscroll check
  delta = orientation vertical ? deltaY : deltaX
  targetScroll += delta * multiplier
  clamp 0..limit se !infinite

raf(time):
  dimensions.resize() se dirty
  lastScroll = animatedScroll
  se animate.isRunning: animate.advance(time); animatedScroll = animate.value
  senao lerp mode: animatedScroll = lerp(animatedScroll, targetScroll, lerp)
  infinite wrap: se <0 => limit+animated, se >limit => animated-limit
  clamp se !infinite
  velocity = animated - last
  direction = sign(velocity)
  escreve DOM: window.scrollTo(0, animated) ou wrapper.scrollTop
  emit scroll event
  se target proximo de animated (<0.01) -> isScrolling false

scrollTo(target, options):
  target: number | string selector | HTMLElement | 'top'|'bottom'|'left'|'right'|'start'|'end'
  resolve:
    number => direto
    'top'/'start' => 0
    'bottom'/'end' => limit
    string #id => getElementById(decodeURIComponent(id)) || querySelector (fix #520 para ids com chars especiais como †)
    string selector => querySelector
    HTMLElement => offsetTop relativo + offset + scroll-margin CSS (fix #507 respeita scroll-margin)
  options: offset, lerp, duration, easing, immediate, lock, force, onComplete, userData
  cria animate.fromTo

stop()/start(): isStopped flag, class lenis-stopped
resize(): dimensions.resize()
destroy(): remove classes, cancel raf, remove listeners

CAPITULO 4: ANIMATE, DIMENSIONS, VIRTUAL-SCROLL, EMITTER, MATHS
================================================================================
Animate:
  from, to, value, lerp, duration, easing, isRunning
  fromTo(from,to,{lerp,duration,easing,onComplete}): seta from/to, currentTime=performance.now(), isRunning true
  advance(time):
    se lerp: value = lerp(value, to, lerp); se abs(to-value)<0.01 => value=to, isRunning false
    senao: t = min(1, (time-start)/(duration*1000)); eased=easing(t); value=from+(to-from)*eased; se t>=1 finish
  QUANTIZE=10 arredonda para detectar fim estavel 120hz

Dimensions:
  wrapper, content, limit {x,y}, width, height
  ResizeObserver no content e wrapper se autoResize true
  resize(): wrapperWidth = window ? innerWidth : clientWidth; contentWidth = scrollWidth; limit = content - wrapper
  scroll getter: window.scrollY ou wrapper.scrollTop

VirtualScroll:
  wheel: deltaY normalizado, deltaMode 0 pixel, 1 line *16, 2 page *innerHeight
  touch: startY, move delta, end velocity = delta/timeDelta, projeta target com exponent
  keyboard: Arrow +-40, Page +-innerHeight*0.9, Space +-innerHeight, Home 0, End limit
  preventDefault apenas se cancelable e target nao e input/textarea/contenteditable (fix IgnoredEventCancel linha 435)

Emitter:
  Map<string, Function[]>
  on/off/emit/destroy - 40 linhas

Maths:
  lerp(a,b,t)=a+(b-a)*t
  clamp(n,min,max)
  damp(a,b,lambda,dt)=lerp(a,b,1-exp(-lambda*dt))
  modulo para infinite

Debounce: setTimeout simples

Types: LenisOptions, ScrollToOptions, LenisScrollEvent

CSS: ja explicado

class Emitter { constructor(){this.events=new Map()} on(e,cb){if(!this.events.has(e))this.events.set(e,[]);this.events.get(e).push(cb);return()=>this.off(e,cb)} off(e,cb){if(this.events.has(e))this.events.set(e,this.events.get(e).filter(f=>f!==cb))} emit(e,...a){this.events.get(e)?.forEach(f=>f(...a))} destroy(){this.events.clear()} }

class Animate { constructor(){this.value=0;this.isRunning=false} fromTo(from,to,{lerp,duration,easing,onComplete}){this.from=from;this.to=to;this.value=from;this.lerp=lerp;this.duration=duration;this.easing=easing||(t=>t);this.currentTime=performance.now();this.isRunning=true;this.onComplete=onComplete} advance(time){if(!this.isRunning)return;if(this.lerp!==undefined){this.value+=(this.to-this.value)*this.lerp;if(Math.abs(this.to-this.value)<0.01){this.value=this.to;this.isRunning=false;this.onComplete?.()}}else{const elapsed=(time-this.currentTime)/1000;const t=Math.min(1,elapsed/this.duration);this.value=this.from+(this.to-this.from)*this.easing(t);if(t>=1){this.value=this.to;this.isRunning=false;this.onComplete?.()}}} }

class Dimensions { constructor(wrapper,content,autoResize){this.wrapper=wrapper;this.content=content;this.limit={x:0,y:0};this.emitter=new Emitter();if(autoResize){this.observer=new ResizeObserver(()=>this.resize());this.observer.observe(content);if(wrapper instanceof HTMLElement)this.observer.observe(wrapper)}this.resize()} resize(){if(this.wrapper===window){this.width=window.innerWidth;this.height=window.innerHeight;this.contentWidth=this.content.scrollWidth;this.contentHeight=this.content.scrollHeight}else{this.width=this.wrapper.clientWidth;this.height=this.wrapper.clientHeight;this.contentWidth=this.content.scrollWidth;this.contentHeight=this.content.scrollHeight}this.limit={x:this.contentWidth-this.width,y:this.contentHeight-this.height};this.emitter.emit('resize',this.limit)} on(e,cb){this.emitter.on(e,cb)} destroy(){this.observer?.disconnect()} }

class VirtualScroll { constructor(target,{wheelMultiplier=1,touchMultiplier=1}={}){this.target=target;this.wheelMultiplier=wheelMultiplier;this.touchMultiplier=touchMultiplier;this.emitter=new Emitter();this.touchStart={x:0,y:0};target.addEventListener('wheel',this.onWheel.bind(this),{passive:false});target.addEventListener('touchstart',this.onTouchStart.bind(this),{passive:false});target.addEventListener('touchmove',this.onTouchMove.bind(this),{passive:false});target.addEventListener('touchend',this.onTouchEnd.bind(this),{passive:false});target.addEventListener('keydown',this.onKeyDown.bind(this))} onWheel(e){let dx=e.deltaX, dy=e.deltaY;if(e.deltaMode===1){dx*=16;dy*=16}if(e.deltaMode===2){dx*=window.innerWidth;dy*=window.innerHeight}dx*=this.wheelMultiplier;dy*=this.wheelMultiplier;if(e.cancelable)e.preventDefault();this.emitter.emit('scroll',{deltaX:dx,deltaY:dy,event:e})} onTouchStart(e){this.touchStart.x=e.touches[0].clientX;this.touchStart.y=e.touches[0].clientY} onTouchMove(e){const dx=this.touchStart.x-e.touches[0].clientX;const dy=this.touchStart.y-e.touches[0].clientY;this.emitter.emit('scroll',{deltaX:dx*this.touchMultiplier,deltaY:dy*this.touchMultiplier,event:e});this.touchStart.x=e.touches[0].clientX;this.touchStart.y=e.touches[0].clientY} onTouchEnd(e){} onKeyDown(e){let dy=0;if(e.key==='ArrowDown')dy=40;if(e.key==='ArrowUp')dy=-40;if(e.key==='PageDown')dy=window.innerHeight*0.9;if(e.key==='PageUp')dy=-window.innerHeight*0.9;if(e.key==='Home')dy=-999999;if(e.key==='End')dy=999999;if(dy!==0){e.preventDefault();this.emitter.emit('scroll',{deltaX:0,deltaY:dy,event:e})}} on(e,cb){this.emitter.on(e,cb)} destroy(){ } }
