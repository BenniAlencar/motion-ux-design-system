================================================================================
1. CORE - ANIMATE - A FUNÇÃO PRINCIPAL
================================================================================

animate(targets, params)

targets:
- string selector: '.box'
- Element: document.querySelector('.box')
- NodeList: document.querySelectorAll('.box')
- Array de elements: [el1, el2]
- Objeto JS: { myValue: 0 }
- Array de objetos

params:
{
  // Propriedades animáveis:
  x: 100, // translateX
  y: 100, // translateY
  z: 100,
  translateX, translateY, translateZ,
  rotate: 360, // deg
  rotateX, rotateY, rotateZ,
  scale: 2,
  scaleX, scaleY,
  skewX, skewY,
  // CSS:
  opacity: [0,1], // de 0 para 1
  backgroundColor: '#ff0000',
  color,
  // Objeto:
  myValue: 100,

  // Timing:
  duration: 1000, // ms! (não segundos como GSAP) - 1000 = 1s
  delay: 500, // ms
  // ou função: delay: (el, i) => i * 100
  // ou stagger: delay: stagger(100, {from: 'center', grid: [3,3]})

  ease: 'inOutQuad', // ou 'linear', 'inOutQuint', 'outElastic', etc
  // ou spring: ease: 'outElastic(1, .5)' ou objeto spring

  loop: true | number, // true = infinito, 2 = 2 vezes
  alternate: true, // vai e volta (yoyo do GSAP)
  autoplay: true, // default true

  // Callbacks:
  onBegin: (anim) => {},
  onUpdate: (anim) => {},
  onComplete: (anim) => {},
  onLoop: (anim) => {},

  // Composição:
  composition: 'replace' | 'add' | 'blend' // como lida com conflitos
}

Exemplos:

// Básico:
animate('.box', { x: 100, duration: 1000, ease: 'outQuad' })

// De/para:
animate('.box', { 
  x: { from: 0, to: 100 },
  opacity: { from: 0, to: 1 },
  duration: 1000
})

// Array de valores (keyframes):
animate('.box', {
  x: [0, 100, 0],
  rotate: [0, 180, 360],
  duration: 2000,
  ease: 'inOutQuad'
})

// Objeto JS (contador):
let obj = { score: 0 }
animate(obj, {
  score: 100,
  duration: 2000,
  onUpdate: () => console.log(obj.score)
})

// Stagger:
import { stagger } from 'animejs'
animate('.box', {
  x: 100,
  delay: stagger(100, { from: 'center', grid: [3,3], axis: 'y', ease: 'inOutQuad' }),
  duration: 1000
})

// Controle da instância:
const anim = animate('.box', { x: 100, duration: 1000, autoplay: false })
anim.play()
anim.pause()
anim.restart()
anim.reverse()
anim.seek(500) // ms

2. TIMELINE - CREATETIMELINE
================================================================================

Substitui anime.timeline() do v3. Agora é createTimeline().

import { createTimeline } from 'animejs'

const tl = createTimeline({
  defaults: { duration: 1000, ease: 'outQuad' },
  loop: true,
  alternate: true,
  autoplay: true,
  onComplete: () => {}
})

tl.add('.box1', { x: 100 }) // começa em 0
  .add('.box2', { x: 100 }, '-=500') // 500ms antes do fim anterior (overlap)
  .add('.box3', { x: 100 }, '+=200') // 200ms depois
  .add('.box4', { x: 100 }, '<') // junto com anterior
  .add('.box5', { x: 100 }, '<<') // junto com início do anterior? (checar docs)

Position parameter v4:
- Sem segundo param = após anterior
- '+=500' = 500ms depois do fim do anterior
- '-=500' = 500ms antes do fim do anterior
- '<' = início do anterior
- Números absolutos: 1000 = em 1000ms da timeline

Exemplo completo:
createTimeline({ defaults: { duration: 800, ease: 'outQuad' } })
  .add('.title', { y: [100, 0], opacity: [0,1] })
  .add('.subtitle', { y: [50, 0], opacity: [0,1] }, '-=400')
  .add('.button', { scale: [0,1], opacity: [0,1] }, '-=200')

Controle:
tl.play()
tl.pause()
tl.restart()
tl.seek(1000)

3. STAGGER - ATRASO ENTRE ELEMENTOS
================================================================================

import { stagger } from 'animejs'

stagger(value, options)

value: número ms ou valor de propriedade
options:
{
  from: 'first' | 'last' | 'center' | 'random' | number (índice),
  grid: [columns, rows], // para grid
  axis: 'x' | 'y', // só em um eixo
  ease: 'inOutQuad' // ease da distribuição
}

Exemplos:
delay: stagger(100) // 0, 100, 200, 300...
delay: stagger(100, { from: 'center' }) // do centro para fora
delay: stagger(100, { from: 'random' }) // aleatório
delay: stagger(100, { grid: [3,3], from: 'center', axis: 'y' }) // grid

Pode usar em qualquer propriedade, não só delay:
x: stagger(100, { from: 'center' }) // x = 0, 100, 200... mas com distribuição

6. SCROLL - ONSCROLL - SCROLLTRIGGER DO ANIME.JS
================================================================================

import { onScroll } from 'animejs'

onScroll(params)

params:
{
  target: '.box',
  enter: 'bottom top', // quando entra
  leave: 'top bottom', // quando sai
  sync: true | number, // amarra ao scroll (scrub)
  onEnter: () => {},
  onLeave: () => {},
  onUpdate: (self) => { self.progress } // 0-1
}

Exemplo:
onScroll({
  target: '.box',
  enter: 'bottom top',
  leave: 'top bottom',
  sync: 0.5, // 0.5s de suavização
  onUpdate: self => {
    animate('.box', { x: self.progress * 500, duration: 0 })
  }
})

// Parallax simples:
onScroll({
  target: '.parallax',
  sync: true,
  onUpdate: self => {
    animate('.parallax', { y: self.progress * -200, duration: 0 })
  }
})

7. SCOPE - CREATESCOPE - PARA REACT/VUE
================================================================================

import { createScope } from 'animejs'

const scope = createScope({ root: '.container' })

scope.add(self => {
  self.add('.box', { x: 100 })
})

scope.revert() // mata tudo

Para React:
function Component(){
  const root = useRef(null)
  const scope = useRef(null)
  
  useEffect(()=>{
    scope.current = createScope({ root: root.current }).add(self=>{
      self.add('.box', { x: 100, duration: 1000 })
    })
    return () => scope.current.revert()
  },[])

  return <div ref={root}><div className="box" /></div>
}

10. COMPARATIVO ANIME.JS v4 vs GSAP vs MOTION
================================================================================

Bundle:
- Anime.js v4: ~9kB gzipped, modular
- GSAP: 20kB core + plugins, ~35kB com ScrollTrigger
- Motion: ~20kB

Sintaxe:
- Anime.js: animate(targets, {x:100, duration:1000}) - ms, simples
- GSAP: gsap.to(targets, {x:100, duration:1}) - segundos, mais verboso mas mais controle
- Motion: <motion.div animate={{x:100}} transition={{duration:1}} /> - declarativo React

Timeline:
- Anime.js: createTimeline().add().add()
- GSAP: gsap.timeline().to().to() com position "<", "+=0.5" (mais poderoso)
- Motion: variants + staggerChildren

Stagger:
- Anime.js: stagger(100, {from:'center', grid:[3,3]}) - excelente
- GSAP: stagger: {each:0.1, from:'center', grid:[3,3]} - similar, mais opções
- Motion: staggerChildren

Scroll:
- Anime.js: onScroll({sync:true}) - básico, bom para parallax simples
- GSAP: ScrollTrigger com pin, scrub, snap, horizontal, markers - padrão ouro
- Motion: useScroll + useTransform - bom para React

SVG:
- Anime.js: svg.createDrawable, morphTo, motionPath - bom
- GSAP: DrawSVG, MorphSVG, MotionPath - mais avançado e testado

Performance:
- Anime.js v4: ótima, 60fps, leve
- GSAP: melhor para 1000+ elementos, ticker único, transform cache
- Motion: melhor para React, MotionValues sem re-render

QUANDO USAR ANIME.JS v4:
- Projeto vanilla JS leve que precisa de animação sem peso
- Quer bundle pequeno (~9kB)
- Sintaxe simples, rápida de aprender
- Não precisa de scroll storytelling complexo
- Alternativa moderna ao GSAP para casos simples

QUANDO USAR GSAP:
- Scroll storytelling, pin, horizontal
- Timeline complexa
- SVG avançado
- 1000+ elementos
- Precisa controle absoluto

QUANDO USAR MOTION:
- React / Next.js
- Layout animations
- Micro-interações
