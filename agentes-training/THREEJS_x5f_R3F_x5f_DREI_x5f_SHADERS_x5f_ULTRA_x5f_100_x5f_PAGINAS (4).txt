================================================================================
1. THREE.JS - O MOTOR POR DENTRO
================================================================================

Three.js é um wrapper em cima de WebGL. WebGL é baixo nível (shaders, buffers).
Three.js abstrai em objetos: Scene, Camera, Mesh, Geometry, Material, Renderer.

Fluxo interno:
Scene (grafo) -> Camera (matriz de projeção) -> Renderer (WebGLRenderer desenha triangulos)

Um Mesh = Geometry (forma) + Material (como parece)

Instalação:
npm install three
import * as THREE from "three"

OU com R3F:
npm install three @react-three/fiber @react-three/drei

Estrutura mínima vanilla Three.js:
import * as THREE from "three"
const scene = new THREE.Scene()
const camera = new THREE.PerspectiveCamera(75, window.innerWidth/window.innerHeight, 0.1, 1000)
const renderer = new THREE.WebGLRenderer({antialias: true, alpha: true})
renderer.setSize(window.innerWidth, window.innerHeight)
document.body.appendChild(renderer.domElement)

const geometry = new THREE.BoxGeometry(1,1,1)
const material = new THREE.MeshStandardMaterial({color: 0xff0000})
const cube = new THREE.Mesh(geometry, material)
scene.add(cube)
camera.position.z = 5

function animate(){
  requestAnimationFrame(animate)
  cube.rotation.x += 0.01
  renderer.render(scene, camera)
}
animate()

4. MATERIAIS - PBR EXPLICADO
================================================================================

PBR = Physically Based Rendering. Baseado em luz real.

Materiais principais:

MeshBasicMaterial - ignora luz, cor plana, mais rápido
  {color, map, wireframe, transparent, opacity}

MeshLambertMaterial - luz simples, não brilhante

MeshPhongMaterial - brilho especular antigo
  {color, shininess, specular, map}

MeshStandardMaterial - PBR padrão (metal/roughness) - MAIS USADO
  {
    color,
    metalness: 0-1 (0 = dieletrico/plastico, 1 = metal),
    roughness: 0-1 (0 = espelho, 1 = fosco),
    map: textura cor,
    normalMap: detalhe de relevo,
    roughnessMap,
    metalnessMap,
    aoMap: oclusão,
    emissive: cor que emite luz,
    emissiveMap,
    envMap: reflexão
  }

MeshPhysicalMaterial - estende Standard com clearcoat, transmissão (vidro)
  {
    transmission: 0-1 (vidro),
    thickness,
    ior: índice refração (1.5 vidro),
    clearcoat: 0-1,
    clearcoatRoughness,
    sheen, iridescence
  }

Outros:
MeshToonMaterial - cartoon com gradientMap
MeshMatcapMaterial - usa matcap texture
ShaderMaterial - shader custom (vertexShader, fragmentShader, uniforms)
RawShaderMaterial - sem includes do Three
PointsMaterial - para Points
LineBasicMaterial - para Line

Texturas em material:
const loader = new THREE.TextureLoader()
const map = loader.load('/texture.jpg')
map.colorSpace = THREE.SRGBColorSpace
map.wrapS = map.wrapT = THREE.RepeatWrapping
map.repeat.set(2,2)

const material = new THREE.MeshStandardMaterial({map})

7. REACT THREE FIBER - O RECONCILER
================================================================================

R3F é um reconciler custom do React que transforma JSX em objetos Three.js.

Invés de:
const mesh = new THREE.Mesh(geometry, material)

Você escreve:
<mesh>
  <boxGeometry />
  <meshStandardMaterial />
</mesh>

Isso é possível porque R3F mapeia tags para classes Three.js e props para propriedades.

CANVAS:
import {Canvas} from "@react-three/fiber"

<Canvas
  camera={{position: [0,0,5], fov: 75}}
  shadows
  dpr={[1,2]} // pixel ratio
  gl={{antialias:true, alpha:true, powerPreference:"high-performance"}}
  frameloop="always" // "always" | "demand" (só renderiza quando muda) | "never"
  flat // sem toneMapping
  linear // sem sRGB
>
  <MeuCena />
</Canvas>

Props mapeadas:
<mesh position={[1,2,3]} rotation={[0,Math.PI,0]} scale={2} />
= mesh.position.set(1,2,3)

<meshStandardMaterial color="red" metalness={0.5} roughness={0.2} />
kebab-case vira camelCase:
<meshStandardMaterial color="red" metalness={0.5} />

Com attach:
<mesh>
  <boxGeometry args={[1,1,1]} /> // args = argumentos do construtor
  <meshStandardMaterial />
</mesh>

args é array de argumentos: new BoxGeometry(1,1,1) => args={[1,1,1]}

HOOKS - SÓ DENTRO DE <Canvas>:

useFrame((state, delta) => {}) - roda a cada frame
  state = {scene, camera, gl, size, viewport, clock, mouse, pointer}
  delta = tempo desde último frame

  function Box(){
    const ref = useRef()
    useFrame((state, delta) => {
      ref.current.rotation.x += delta
    })
    return <mesh ref={ref}><boxGeometry/><meshStandardMaterial/></mesh>
  }

  Com ordem: useFrame((state,delta)=>{}, 1) // 1 = ordem, -1 roda antes

useThree() - acesso ao estado
  const {camera, scene, gl, size, viewport, clock} = useThree()
  // seletor para evitar re-render:
  const camera = useThree(s => s.camera)

useLoader(Loader, url) - carrega
  const texture = useLoader(THREE.TextureLoader, '/tex.jpg')
  const gltf = useLoader(GLTFLoader, '/model.glb')

useGraph(object) - extrai materiais

createPortal - renderiza fora da cena mas com contexto

useRef + mutação direta = performance:
  NUNCA use useState para animar posição! Use ref + useFrame para mutar direto, senão React re-renderiza 60fps e mata performance.

Frameloop demand:
<Canvas frameloop="demand">
  // só renderiza quando props mudam ou invalidate() chamado
  // bom para site estático 3D

Exemplo completo R3F:
import {Canvas, useFrame} from "@react-three/fiber"
import {useRef} from "react"

function SpinningBox(props){
  const meshRef = useRef()
  useFrame((state, delta) => {
    meshRef.current.rotation.x += delta * 0.5
    meshRef.current.rotation.y += delta * 0.2
  })
  return (
    <mesh ref={meshRef} {...props}>
      <boxGeometry args={[1,1,1]} />
      <meshStandardMaterial color="orange" />
    </mesh>
  )
}

function App(){
  return (
    <Canvas camera={{position:[0,0,5]}}>
      <ambientLight intensity={0.5} />
      <directionalLight position={[10,10,5]} intensity={1} />
      <SpinningBox position={[0,0,0]} />
      <OrbitControls />
    </Canvas>
  )
}

Performance - regras de ouro:
1. NUNCA use useState dentro de useFrame - use ref
2. Use InstancedMesh para 1000+ objetos iguais
3. Limite dpr a [1,2] - dpr 3 em mobile mata
4. Frameloop="demand" se cena estática
5. Use draco e ktx2 para modelos e texturas (compressão 10x)
6. Dispose: geometry.dispose(), material.dispose() quando desmonta
7. Shadow map 1024 ou 2048, não 4096
8. Use <Suspense> para loaders
9. LOD (Level of Detail) para objetos distantes

SHADERS GLSL + POSTPROCESSING - ENGENHARIA REVERSA TOTAL - NÍVEL DEUS
================================================================================
Shader = programa que roda na GPU. 2 tipos:
Vertex Shader: roda por vértice, posiciona vértice
Fragment Shader: roda por pixel, pinta cor

Three.js já tem shaders internos, mas ShaderMaterial deixa você escrever seu próprio GLSL.

--------------------------------------------------------------------------------
1. SHADERMATERIAL - ANATOMIA
--------------------------------------------------------------------------------
const material = new THREE.ShaderMaterial({
  uniforms: { // variáveis JS -> GPU
    uTime: {value: 0},
    uColor: {value: new THREE.Color('red')},
    uTexture: {value: texture}
  },
  vertexShader: `
    uniform float uTime;
    varying vec2 vUv; // passa para fragment
    varying vec3 vNormal;
    void main(){
      vUv = uv;
      vNormal = normal;
      // deforma vértice
      vec3 pos = position;
      pos.y += sin(pos.x * 5.0 + uTime) * 0.2;
      gl_Position = projectionMatrix * modelViewMatrix * vec4(pos, 1.0);
    }
  `,
  fragmentShader: `
    uniform vec3 uColor;
    uniform float uTime;
    varying vec2 vUv;
    void main(){
      vec3 color = uColor * sin(vUv.x * 10.0 + uTime);
      gl_FragColor = vec4(color, 1.0);
    }
  `,
  transparent: true,
  side: THREE.DoubleSide
})

Uniforms atualiza no useFrame:
useFrame((state)=>{
  material.uniforms.uTime.value = state.clock.elapsedTime
})

GLSL BÁSICO:
float, vec2, vec3, vec4, mat4, sampler2D
sin(), cos(), length(), dot(), cross(), mix(), step(), smoothstep(), fract(), abs()
uv = coordenada 0-1
position, normal, uv já existem

SHADER PATTERNS MATADORES:

1. Gradiente animado:
fragment: 
  vec3 color = mix(vec3(0.0,0.0,1.0), vec3(1.0,0.0,0.0), vUv.x + sin(uTime)*0.2);

2. Fresnel (borda brilhante):
vertex: vNormal = normalize(normalMatrix * normal);
fragment:
  float fresnel = pow(1.0 - dot(vNormal, vec3(0.0,0.0,1.0)), 3.0);
  gl_FragColor = vec4(vec3(fresnel), 1.0);

3. Ruído (precisa incluir glsl-noise):
  float noise = snoise(vUv * 10.0 + uTime);

4. Displace com textura:
vertex:
  float disp = texture2D(uTexture, uv).r;
  pos += normal * disp * 0.5;

Em R3F com shaderMaterial helper (Drei):

--------------------------------------------------------------------------------
2. POSTPROCESSING - EFFECTCOMPOSER
--------------------------------------------------------------------------------

Pipeline: cena -> RenderPass -> passes (Bloom, etc) -> OutputPass -> tela

Vanilla Three.js:
import {EffectComposer} from 'three/addons/postprocessing/EffectComposer.js'
import {RenderPass} from 'three/addons/postprocessing/RenderPass.js'
import {UnrealBloomPass} from 'three/addons/postprocessing/UnrealBloomPass.js'
import {OutputPass} from 'three/addons/postprocessing/OutputPass.js'

const composer = new EffectComposer(renderer)
composer.addPass(new RenderPass(scene, camera))
const bloomPass = new UnrealBloomPass(new THREE.Vector2(w,h), 1.5, 0.4, 0.85)
bloomPass.threshold = 0.1
bloomPass.strength = 1.2
bloomPass.radius = 0.5
composer.addPass(bloomPass)
composer.addPass(new OutputPass())

No animate: composer.render() ao invés de renderer.render()

Em R3F - @react-three/postprocessing (muito mais fácil):
import {EffectComposer, Bloom, ChromaticAberration, Vignette, Noise, Glitch, DepthOfField, GodRays, SSAO} from "@react-three/postprocessing"
import {BlendFunction} from "postprocessing"

function ShaderMesh(){
  const ref = useRef()
  const matRef = useRef()
  useFrame((state)=>{
    matRef.current.uniforms.uTime.value = state.clock.elapsedTime
  })
  return (
    <mesh ref={ref}>
      <planeGeometry args={[3,3,128,128]} />
      <shaderMaterial
        ref={matRef}
        uniforms={{
          uTime: {value: 0},
          uColor: {value: new THREE.Color('#ff00ff')}
        }}
        vertexShader={`
          uniform float uTime;
          varying vec2 vUv;
          void main(){
            vUv = uv;
            vec3 pos = position;
            pos.z += sin(pos.x * 3.0 + uTime) * 0.2;
            pos.z += sin(pos.y * 3.0 + uTime) * 0.2;
            gl_Position = projectionMatrix * modelViewMatrix * vec4(pos, 1.0);
          }
        `}
        fragmentShader={`
          uniform vec3 uColor;
          varying vec2 vUv;
          void main(){
            float strength = distance(vUv, vec2(0.5));
            gl_FragColor = vec4(uColor, 1.0);
          }
        `}
      />
    </mesh>
  )
}
