# Hero Scroll Next.js Template

Template pronto para usar com GSAP ScrollTrigger + Lenis.

## Instalacao

```bash
npm install
```

## Desenvolvimento

```bash
npm run dev
```

## Build

```bash
npm run build
npm run start
```

## Lighthouse

```bash
npm run lighthouse
```

## Estrutura

```
app/
├── layout.tsx
├── page.tsx
└── components/
    └── HeroScroll.tsx
```

## Como Usar

1. Copiar `HeroScroll.tsx` para seu projeto
2. Substituir placeholders pelos assets reais
3. Ajustar cores e tipografia conforme sua marca
4. Rodar Lighthouse para validar performance

## Assets Necessarios

- Logo (SVG ou PNG)
- Hero background image
- Product shots (2-3 imagens)

Ver `skills/asset-gate/examples/asset-instructions-output.md` para especificacoes completas.
